# Apollo Hospital Healthcare Analytics & AI Forecasting Dashboard

## Project Overview

This project is a real-world Healthcare Analytics Dashboard created using hospital patient data. The dashboard helps analyze patient trends, hospital performance, disease growth, emergency cases, revenue generation, and future healthcare forecasting using AI analytics concepts.

The project is developed using:

- Power BI
- Python
- Pandas
- Seaborn
- Matplotlib

---

# Project Objectives

The main objectives of this project are:

- Analyze hospital patient data
- Monitor disease trends
- Track hospital revenue
- Analyze emergency patients
- Improve healthcare decision-making
- Predict future patient growth
- Forecast hospital revenue
- Optimize hospital resources
